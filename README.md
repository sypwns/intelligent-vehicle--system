# ML-Based Intelligent Vehicle System for Monitoring, Diagnostics, Weather Safety, and Remote Control

## Project Overview
This diploma project proposes a mobile application that combines vehicle monitoring, machine-learning-based diagnostics, maintenance assistance, weather-aware route recommendations, and remote control through supported interfaces.

## Problem Statement
Drivers may find it difficult to interpret diagnostic information and combine vehicle condition with weather and road information when planning journeys. The project will investigate how these inputs can support understandable maintenance and travel recommendations.

## Target Users
The intended users are drivers and vehicle owners, particularly those who need clear explanations of technical information. User needs have not yet been validated through discussions.

## Aim
To develop a mobile vehicle-management prototype and evaluate whether adding vehicle-health indicators improves the appropriateness of weather-aware route recommendations.

## Planned Features
- Vehicle condition monitoring.
- Machine-learning-based diagnostics.
- Plain-language diagnostic explanations and maintenance advice.
- Personalised maintenance planning.
- Weather and road risk assessment with route recommendations.
- Remote control through supported interfaces; specific commands remain to be defined.

## Research Evaluation
Two recommendation configurations will be compared:
1. Weather and road-condition inputs.
2. The same inputs combined with vehicle-health indicators.

Both configurations will use matched scenarios and independently reviewed reference assessments. No experimental results are available yet.
